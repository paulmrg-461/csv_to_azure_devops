# Reglas de specs/ (carga automática al trabajar aquí)

1. Esta carpeta contiene SOLO las plantillas del framework. NO las edites ni las rellenes aquí: cópialas a su destino (ver tabla del README) y rellena la copia.
2. Las specs reales y los cambios NO viven aquí: están en `.sdf/docs/<id>/` (spec.md + changes/), la carpeta espejo del documento `docs/<id>.<ext>`.
3. Si falta una plantilla o parece desactualizada, repórtalo al usuario — las plantillas se corrigen actualizando el framework (skill SDF), no editándolas por proyecto.
